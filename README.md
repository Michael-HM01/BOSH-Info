# Informative Website: BOSH & Environmental Engineering

An educational web application developed as a coursework project for **Basic Occupational Safety and Health (BOSH)** and **Environmental Engineering**. This platform serves as a centralized resource hub featuring detailed academic materials, interactive minigames, and developer contacts.

## Key Features

* **Central Homepage:** Easy navigation routing to both subject-specific portals, a community bulletin board, and developer contact details.
* **Comprehensive Course Content:** In-depth information and reference materials tailored for student learning and research.
* **Interactive Minigames:** Includes subject-focused quizzes and word searches to reinforce key concepts through gamification.
